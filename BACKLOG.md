# Hari Bersama feature backlog

These features come from the kondangan.app dashboard review. The core release covers invitation customization, saved drafts, and guest management. The items marked for consideration are follow-up ideas.

## First release

1. **Design.** Add separate backgrounds for the cover and couple profiles. Offer photo frames, section dividers, and optional animated decorations that fit the selected template. Build on the Studio's existing palette, fonts, cover photo, and section styles. [Reference](https://kondangan.app/dashboard/design)
2. **Content.** Add ready-to-fill blocks for each partner's profile and parents, and a relationship timeline with a date, title, location, and short description per entry. Extend the existing rundown so each agenda item can have its own date, time, venue, Maps link, and calendar action. [Reference](https://kondangan.app/dashboard/content)
3. **Overview.** Let signed-in creators save and reopen their drafts. Show draft or published status, sharing links, and a summary of RSVP responses. Reuse the Studio's phone and desktop previews. Keep existing guest links working when published details are edited. [Reference](https://kondangan.app/dashboard)

## Follow-up releases

4. **Guests.** Keep the guest list accessible after publication. Add search, filters for accepted, declined, and unanswered RSVPs, and a WhatsApp share action per guest. Support CSV upload and paste from a spreadsheet with name, phone, and email columns. Skip duplicate entries without discarding existing RSVPs. Consider Google Contacts import after CSV. [Reference](https://kondangan.app/dashboard/guests)
5. **More content blocks.** Add optional blocks for a quote or scripture, livestream links, and gifts with copyable bank or e-wallet details. Consider video in the gallery after the photo workflow. [Reference](https://kondangan.app/dashboard/content)
6. **Music.** Add custom audio upload, start and end points, loop playback, and an editor preview alongside the existing catalog. Let guests control playback. Consider YouTube input separately. [Reference](https://kondangan.app/dashboard/music)
7. **Check-in.** Give each guest a QR code. Track ceremony and reception check-ins separately, with name search as a fallback to camera scanning. Consider sound and volume settings after both check-in paths work. [Reference](https://kondangan.app/dashboard/check-in)
8. **Issue reporting.** Add a short report form accessible from the Studio or preview. Consider report history and replies once the form is in use. [Reference](https://kondangan.app/dashboard/reports)
